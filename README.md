# 恋爱沟通 · dating-communication

结合消息意图、关系阶段、近期互动和边界，判断眼下适合怎么聊。支持日常口语拟回复、聊天记录分析、邀约和关系维护。

**版本 0.1.1 · MIT License**

这是供支持 `SKILL.md` 的 AI 助手使用的 Skill，无额外运行依赖。入口为 [SKILL.md](SKILL.md)。

## 能做什么

- **判断下一步**。结合关系和当前互动，选择接话、倾听、澄清、落实约定、邀约或暂缓。
- **回复与润色**。有足够的可行策略时，默认给 3 条沟通目的不同的候选，附 0–100 推荐值和短理由。评分综合自然度、关系与时机、意图与情绪、边界与负担。
- **旧聊天分析与简报**。整理熟悉程度、双方主动性、浪漫表达、约定与兑现情况。记录有依据的偏好、共同经历和有效边界，标明未知项。
- **反馈与练习**。结合实发消息和对方回应复盘，沿用用户明确纠正的说法。也支持交友简介和角色模拟。

推荐值只比较当前候选的适配程度，不代表对方好感或成功概率。用户指定的条数与格式优先，例如“只回一句，不评分”。

## 使用

下载或克隆本仓库，将完整的 `dating-communication` 目录放入所用工具支持的 Skills 目录。保留 `references/`、`assets/` 和 `agents/`，由助手按当前任务读取所需内容。

```text
使用 $dating-communication。
我们认识一周，下面是最近的对话。我想自然地约一次见面，
给3条候选、推荐值和简短理由。
```

分析旧聊天时，提供记录并说明说话方：

```text
使用 $dating-communication。下面的记录里，我是A，对方是B。
先分析关系程度、互动是否双向，以及对方明确提过的偏好和沟通习惯。
把依据和不确定的地方写清，整理成后续能继续用的简报，再建议下一步。
```

可提供文本、可读截图与表情包、语音转写，或助手能够读取的导出文件。实际可读取的格式取决于所用工具。[历史分析指南](references/history.md) · [关系简报模板](assets/relationship-context.md)

简报默认在当前对话使用。用户要求时可保存文件，或把简报带到新对话。补充新消息和纠正时，只更新受影响的内容。角色模拟可指定“逐轮辅导”或“连续模拟，结束再点评”。

## 文件结构

- `SKILL.md`：能力入口、任务路由和默认输出。
- `references/`：关系、意图、策略、风格、生成、评估、记忆、反馈和各场景指南。
- `assets/relationship-context.md`：关系简报空白模板。
- `agents/openai.yaml`：界面显示信息和默认调用提示。
