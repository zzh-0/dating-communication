# 恋爱沟通 · dating-communication

用日常口语拟回复，从旧聊天记录整理关系程度和沟通画像，辅助聊天、邀约与关系维护。

**版本：0.1.0 · MIT License**

这是供支持 `SKILL.md` 的 AI 助手使用的 Skill，无额外运行依赖。入口为 [SKILL.md](SKILL.md)。

## 能做什么

- **回复与润色**：默认给3条候选，附0–100分推荐值、首选和简短理由。按上下文与用户自己的表达习惯调整，不强行接梗或升温。
- **旧聊天分析**：整理熟悉程度、双向参与、浪漫表达、约定与兑现情况；记录对方明确表达的偏好和可观察的沟通习惯，区分事实、推测和未知项。
- **邀约与关系维护**：结合当前互动给行动选项，也支持交友简介、聊天复盘和角色模拟。

推荐值只比较当前候选的适配程度，不代表对方好感或成功概率。用户指定的条数与格式优先，例如“只回一句，不评分”。

## 使用

下载或克隆本仓库，将完整的 `dating-communication` 目录放入所用工具支持的 Skills 目录。保留 `references/`、`assets/` 和 `agents/`，由助手按当前任务读取所需内容。

```text
使用 $dating-communication。
我们认识一周，下面是最近的对话。我想自然地约一次见面，
给3条候选、推荐值和简短理由。
```

分析旧聊天时，提供记录并说明说话方：

```text
使用 $dating-communication。下面的记录里，我是A，对方是B。
先分析关系程度、互动是否双向，以及对方明确提过的偏好和沟通习惯。
把依据和不确定的地方写清，整理成后续能继续用的简报，再建议下一步。
```

可提供文本、可读截图，或助手能够读取的导出文件。实际可读取的格式取决于所用工具。分析方法见 [历史分析指南](references/history.md)，输出可用 [关系简报模板](assets/relationship-context.md)。

简报默认只在当前对话使用；用户要求保存时才写入文件。后续可补充新消息，更新有变化的判断。角色模拟可指定“逐轮辅导”或“连续模拟，结束再点评”。

## 文件结构

- `SKILL.md`：能力入口、任务路由和默认输出。
- `references/`：回复、历史分析、互动判断、关系维护、简介与练习指南。
- `assets/relationship-context.md`：关系简报空白模板。
- `agents/openai.yaml`：界面显示信息和默认调用提示。
