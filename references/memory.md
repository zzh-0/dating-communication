# 关系简报的记忆与更新

沿用 [关系简报模板](../assets/relationship-context.md)。新对话中只使用用户主动提供的简报或文件；旧简报缺少新字段时照常读取，缺项标未知。只沿用与当前对象及任务有关的部分。身份或范围不清且会影响行动时先确认，不能把不同人的边界、经历与偏好合并。

| 记录内容 | 适用范围和更新 |
| --- | --- |
| 用户口气与沟通偏好 | 明确自述、明确纠正或有反复样本的习惯；区分本次要求和长期偏好，注明适用场景 |
| 对方明确偏好、边界和共同经历 | 每项注明说话方、时间、来源和适用范围；经历保留实际发生的部分，边界按原话的条件或时段有效 |
| 近期状态、待办和约定 | 保留当前有效条件、责任方、时间；完成、撤销、改期或过期就更新，含糊部分保留未知 |
| 关系与互动判断 | 注明观察窗口和关键反证，分开记录双方确认的身份与可修正的观察；旧状态不自动代表现在 |
| 反馈所得 | 保留下一次确实可用的语言偏好、修正项和需避免的重复建议，记录来源及作用范围 |

长期保留项写必要摘要和证据编号。来源可以是用户明确说明、对方原话、可观察事件或实际实发消息。助手建议、候选评分、模拟结果和旧推测不能成为新事实。只保存有实际后续用途的内容；近期事件、推测和过期约定各自标明状态。

## 有新输入时

1. 核对对象、时间与同一事件的来源，去重并沿用已有证据编号。重复导入不增加主动性或置信程度。
2. 只重审受影响条目。明确纠正优先于旧推测，写清撤销哪条和新依据；不同场景的偏好可以并存。新信息冲突且无法确认时保留冲突、待核对，先使用仍可靠的部分。
3. 完成或失效的事项退出当前待办。已明确的无期限限制持续有效；新的普通分享只更新这次互动，不能凭空撤销旧边界。
4. 用更新后的简报做决策。用户只问下一句时带入相关内容即可；询问变化时简短说明改了什么以及影响哪类建议。

默认在当前对话使用。只有用户明确要求保存时才写文件，按指定位置；无指定位置且项目有 Git 忽略的 `private/` 时可用该目录。无法写文件就交付可复制的简报。保存范围限于用户要求和必要字段，私人记录不进入 Skill 或版本库。没有用户提供的简报时，不宣称能自动恢复跨对话记忆。
