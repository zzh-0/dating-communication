# 关系阶段、互动状态和边界

把**双方认可的关系身份、可观察的熟悉和往来、眼下这段对话的状态**分别判断。先记录用户给的背景，再用聊天与已知事件补充。标签证据不足时用“身份未确认”“熟但关系不明”等描述。熟人、暧昧或伴侣都可能只想聊一件日常小事。

| 已知阶段或模式 | 常见沟通目标 | 做决策时需要的依据 |
| --- | --- | --- |
| 刚认识 | 从对方主动给出的细节认识其兴趣，建立舒适的来回交流 | 对方实际分享的内容与意愿，少用共同经历、专属称呼或未来安排 |
| 朋友 | 接住近况、用真实共同话题续聊、给双方平时会给的支持 | 已有共同经历和玩笑尺度，明确的朋友定位优先 |
| 暧昧 | 用户有意且彼此有过类似表达时，可以回应调情、延续一个双方参与的后续话题，或轻量确认下一步 | 双向调情、明确约会意向或对方给过的安排；单方喜欢与友好分享不够 |
| 恋人 | 维持亲密和日常联系、回应已有约定、一起处理实际需要或分歧 | 双方确认的关系、称呼、约定及对本次安排或接触的实际意愿 |
| 未确认或有争议 | 先解决眼前话题，确实需要时直接确认双方期待 | 标明是谁的说法和仍缺什么；支持保留现状或退出 |

## 判断眼下状态

按相关话题和相邻时段比较，优先看完整话轮与本人平时习惯。分开看发起对话、接住话题、主动补细节、事后回访，以及是否提出、确认或兑现具体安排。主动发消息和认真接话都是参与；一方发起多，另一方也可能承担延续或协调。消息数量、回复时长、单次沉默或连发短句只能说明局部情况，缺窗口就写未知。

| 当前状态 | 可用线索 | 对下一步的影响 |
| --- | --- | --- |
| 热络 | 双方主动补充、接梗、回访或落实计划 | 可以顺着共同话题延展；更亲密的表达仍看真实先例与意愿 |
| 平稳 | 回复节奏符合平时，日常来回顺畅，话题可以自然结束 | 普通回应或顺手处理已有事项即可 |
| 冷淡或参与偏低 | 相对近期基线，连续多个话轮少接续，重要提议长期无回应或反复没有安排 | 降低负担，少追问，已完整的消息可以停；动机保留未知 |
| 紧张 | 明确表达不舒服、争执或同一问题反复受阻 | 先处理不适与必要边界，暂停调侃或推进 |
| 可能有误会 | 双方回应了不同问题，引用或语音转写有歧义，某句被明确指出理解错了 | 确认一个影响最大的点；已有过错就先承担，再谈下一步 |

状态可并存或按话题变化。记录“近期整体平稳，排期这件事有误会”比替整个关系贴标签有用。总结长期情况时保留熟悉、双向参与、浪漫表达与身份、安排兑现四项，见 [历史分析](history.md)。

## 范围与时机

按限制对象区分话题、时间、活动、见面、接触和联系。主动提出替代就正常协调；明确不愿见就停止邀约，明确停止联系就停止，过去热情或本次普通分享不解除限制。短期暂缓条件结束后仍需要确认意愿。双方同意联系、交往、赴约或某次接触，都只涵盖各自明确同意的范围。细节见 [互动情境](signals.md)。

判断推进时机时同时检查用户真实意愿、对方对应层面的行为、尚未解决的冲突和当前负担。例如愿意聊音乐可以继续聊音乐；有来回交流和真实的共同活动兴趣时，可应用户意愿邀请一次，接下来再按对方接受、改期或拒绝处理。证据有限时优先选轻量、可停下的行动，或说明需要补的具体事实。
