# 候选评估与推荐值

先筛掉编造、误认说话方、明显不接题、违背用户真实意愿、绕过拒绝、施压或冒犯边界的做法。边界清楚且不该发时，以暂缓或停止为首选。依赖关键未知事实的做法先核对，或明示条件供用户判断。

对留下的选项检查四项：

| 维度 | 判断依据 |
| --- | --- |
| 自然度 | 可发文字像用户本人或合适的日常口语，信息足够，少套话；行动本身也容易执行 |
| 关系与时机 | 适合已知关系、近期往来、眼下时机与未完事项，称呼和推进尺度有依据 |
| 意图与情绪 | 回答明确问题，符合对方表达的需要；情绪不明时仍接得上已知内容 |
| 边界与负担 | 保留对方选择和退出空间，用户能做到，不给对方增加不必要的解释、答复或行动负担 |

用 0–4 粗评每项。4 表示贴合且依据充分，3 表示合适，2 表示有清楚的取舍或需满足一个条件，1 表示适配较弱，0 表示明显不合适。任何一项为 0，回到策略调整或删除。四项等权，将总分按满分 16 换成 0–100，再取到最近的 5 分；并列允许。若 1–2 分的短板涉及有效边界或关键事实，按前面的筛选处理。用户通常只需要看到总推荐值和一条可比较的理由，需要复核时再给维度明细。

高分表示眼下比较适合，条件型方案要写明前提。分数不用于估计好感、感情程度或答应概率，也不参与更新关系画像。排序优先依据用户要做的事和对方明确说过的话；分数相近时可并列，或说明“想续聊选这一条，想收尾选另一条”。
